# ИРНР — информационный портал (учебный макет)

Адаптивный статический сайт для вымышленного проекта ИРНР. Использует только HTML, CSS и JavaScript, без сборки и зависимостей.

## Что включено

- Главная страница и адаптивное меню.
- Новости с модальным окном публикации.
- Раздел вымышленных учреждений.
- Архив документов с поиском, фильтром и просмотром текста.
- Переключение светлой и тёмной темы.
- Игровой конвертер условных валют.
- Демо-форма обращений и локальный профиль.
- Мобильная адаптация.

## Важно о формах и личном кабинете

GitHub Pages размещает статические файлы. В этом макете профиль и обращения сохраняются в `localStorage` конкретного браузера. Они не отправляются владельцу сайта и не синхронизируются между устройствами. Это не защищённая авторизация. Не собирайте через этот шаблон пароли, паспортные данные, адреса или другие чувствительные сведения.

Для настоящих аккаунтов и отправки форм нужна серверная часть или специализированный сервис с безопасной аутентификацией, защитой данных и правилами хранения.

## Как посмотреть сайт локально

1. Скачайте все файлы в одну папку.
2. Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте **Public repository**, например `irnr-portal`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь публикации. Адрес обычно будет `https://ВАШ-ЛОГИН.github.io/irnr-portal/`.
7. Если адрес не появился сразу, обновите раздел Pages через минуту или две.

## Как менять новости

Откройте `script.js` и отредактируйте массив `newsItems` в начале файла. Для каждой новости укажите:
- `id` — уникальный идентификатор латиницей;
- `date` — дата в формате `YYYY-MM-DD`;
- `category` — категория;
- `title` — заголовок;
- `summary` — короткое описание;
- `body` — полный текст публикации.

## Как менять документы

В этом же файле отредактируйте массив `documents`. Категории, используемые фильтром: `Основной закон`, `Дипломатия`, `Административные`.

## Как изменить игровые курсы

В `script.js` найдите объект `currencyRates`. Числа — условные курсы по отношению к общей игровой базовой единице. Это не реальные валюты и не финансовые котировки.

## Как изменить цвета

В начале `style.css` отредактируйте CSS-переменные внутри `:root`. Цвета тёмной темы находятся в `:root[data-theme="dark"]`.
